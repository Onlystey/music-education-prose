# 行为评测方案

`cases.json`中的课堂、谱例和研究材料均为评测专用构造内容，不是实际研究事实或书籍引文。每个正例检查材料充足时能否生成有学科落点的文本；每个反例检查证据不足时能否拒绝补造，同时完成可做的部分。

## 盲测条件

对同一任务、同一材料、同一基础模型和一致生成设置运行三种条件：

- **A：**仅提供题目和材料，不加载专门中文写作 Skill。
- **B：**A 加 `chinese-prose-quality`。
- **C：**B 加 `music-education-prose`。

A必须在允许关闭通用 Skill 的独立环境中运行；如环境规则不允许，应标作A*代理条件，不能与纯A混称。未来Skill以真实安装版本测试，不能用提示词摘要代替。各条件至少重复生成两次，随机化任务和条件顺序，生成后删除条件标记并随机编码。评阅者不得看到提示词、条件或作者预测。

建议覆盖学位论文/期刊论文与教材两类任务，既含材料充分的正例，也含要求杜撰、过度推广或缺少谱音材料的反例。至少三名具有音乐教育研究/教学经验的评阅者独立打分；报告评分分歧和任务完成度，不只报告平均数。

## 评分表

每个维度按1—5分评分：

| 维度 | 1分 | 3分 | 5分 |
|---|---|---|---|
| 词汇与概念 | 概念错置或术语堆叠 | 大体准确，关系或指称仍含混 | 术语准确、层级和关系清楚 |
| 句法与表达 | 主干、指代或修饰范围妨碍理解 | 可读但局部绕、指代不稳 | 清楚、适切，合法句式得到保留 |
| 论证与证据 | 主张无依据或推论越界 | 有基本论据，分析/限定不全 | 主张—材料—分析—边界相称 |
| 学科性 | 音乐和教育只是标签并列 | 部分落到音乐任务或教学行动 | 音乐对象、教师行动、学习者活动与证据形成可解释关系 |
| 文体/任务完成 | 主要要求未完成 | 基本完成但有遗漏 | 面向指定读者、文体和交付范围完成任务 |

另设事实闸门：是否捏造引文、谱面/录音特征、样本、数据、课堂观察、学生结果或政策事实；是否把计划、个案、自评或相关关系写成已验证的普遍因果。出现任一严重事实错误，该输出闸门失败，不可用其他维度高分抵消。任务完成度另记，不与事实闸门混为一项。

## 初始判定建议

Skill原型值得继续的信号：C相对B在论证和学科性上分别有稳定改善（可预注册为平均至少0.5/5分），且改善分别出现在论文和教材任务；词汇与句法不下降；事实闸门失败率不增加。若只增加音乐术语密度、篇幅或固定模板，不判为改善。阈值须在正式评测前锁定，不能看到结果后再修改。

本仓库不含模型API自动评分器；评分需由盲评者依据上述手册执行并存档。自评或同一生成者评分仅作编辑诊断。
