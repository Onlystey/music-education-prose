# 证据、论证与推论边界

## 先识别材料类型

不同材料回答不同问题，不能互相替代：

| 材料 | 可支持的判断示例 | 不能单独支持 |
|---|---|---|
| 乐谱、录音、演奏记录 | 对给定材料的音乐特征或表演过程作具体分析 | 所有学习者的反应、教学的普遍效果 |
| 教案、教学设计 | 教师计划了什么目标、内容和活动 | 课堂实际实施、学生已经学会 |
| 课堂观察、录像、逐字记录 | 特定时段中可见的师生行动与互动 | 未观察到的持续表现、单一行动的因果效果 |
| 学生作品、学习单、访谈 | 特定任务下的表现、解释或体验 | 未取样群体的普遍特征、教师的单独因果贡献 |
| 问卷、自评、测验或统计 | 由工具、样本与分析方法支持的变量关系/描述 | 工具未测内容、未取样人群、无设计支持的因果结论 |
| 理论文献、政策文本、作者观点 | 来源所陈述的概念、规范或论证 | 未经检验的课堂事实、效果和适用范围 |

表中例子是方法提醒，不是固定的证据等级排序。具体可支持什么，仍取决于资料设计、来源质量、任务和问题。

## 保留论证链

学术论证可核对下列功能是否出现，而非强制每段按同一顺序：

**主张 → 材料/来源 → 对材料的分析 → 推理连接 → 适用范围或替代解释。**

分析要解释证据为何支持主张。引用理论名、方法名或学者姓名本身不是分析；应说明它解释哪个现象、概念如何对应音乐教育对象、适用边界在哪里。直接引用、转引、作者概括、参与者原话和作者推论要分清。来源缺失时，不编作者、书名、页码、年份或原话。

## 区分设计、实施、反应与结果

- **设计**：计划让教师或学生做什么。
- **实施**：实际课堂发生了什么，有何记录。
- **反应/体验**：学习者或教师如何报告、表达或表现回应。
- **学习结果/效果**：使用何种测量或多源证据判断了什么变化。

这些层次可以相关，但不能把前一层直接写成后一层。例如，活动设计包含创编，不表示学生创造力已提高；一名学生积极回应，不证明全班都受益；两项指标同时变化，也不自动说明因果。将试行方案写成“建议/拟/可”，将未验证命题写成“待检验”。

## 量化研究与研究现状

报告比例、显著性、载荷、效应量或群体差异前，核对原始数据、变量定义、样本来源和分析输出。摘要或OCR内容如有疑点，标待核而不补数。只提供局部材料时，结论只覆盖该局部。

“现状”不是题目标题自动提供的经验事实。没有研究材料时，可以提出调查维度、指标和资料需求，但不能写出教师普遍怎样、目前比例多少、成效如何。若用户要求真正的现状综述且检索工具可用，需另行检索并核查来源；无法核查时说明限制。

## 证据不足时的处理

1. 保留原有判断强度，不把可能、倾向或个案改成确定、普遍或因果结论。
2. 指出缺少的证据及其影响：缺乐谱就不能分析具体音高结构；缺课堂资料就不能断言实施效果；缺样本就不能估计群体分布。
3. 尽可能完成不依赖缺项的概念分析、结构设计或方法建议。
4. 用“材料直接表明”“据此可推测”“本文建议”“有待检验”等表述区分来源和作者解释；不要把标签当作实质分析的替代品。
